# Changelog

## 1.1.0 - 2026-09-25

- Canonical v1 project and export requests use `stateSchemaVersion: "v1"` and tick-based editor timing.
- Typed clients cover exports, editor, projects, uploads, assets, illustrations, and webhooks.
- Export workflows support cancellation, polling, filenames, export phases, and idempotent retries.
- Uploads preserve exact byte lengths, API responses are validated, and resource identifiers are URL-encoded.
- Node.js 18+ and Edge runtimes are supported.
